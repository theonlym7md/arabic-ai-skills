# ArabicSkill

![غلاف ArabicSkill: أشكال مترابطة تمثل الحرف والمسار والواجهة](docs/assets/arabicskill-cover.svg)

**اكتب واجهات عربية تبدأ من حاجة المستخدم، لا من ترجمة النص الإنجليزي.**

مهارة مفتوحة المصدر لوكلاء الذكاء الاصطناعي. تساعدك على كتابة الأزرار والنماذج والتنبيهات، وتوطين المنتجات، واختيار مسار واجهة يناسب جمهورك.

## ابدأ في دقيقة

```bash
npx skills add theonlym7md/arabic-ai-skills --skill arabicskill
```

بعد التثبيت جرّب هذا الطلب:

> استخدم $arabicskill لكتابة عنوان ووصف وزر لدفع لم تتضح نتيجته. لا نعرف هل خُصم المبلغ، لكن يوجد إجراء للتحقق من حالة العملية. اكتب بفصحى واضحة.

| المهارة | متى تختارها؟ |
| --- | --- |
| [arabicskill](https://skills.sh/theonlym7md/arabic-ai-skills/arabicskill) | عندما تحتاج كتابة نصوص منتج، أو تدقيقها، أو توطين رسائل ومنتجات رقمية للعربية |
| [arabic-uiux-master](https://skills.sh/theonlym7md/arabic-ai-skills/arabic-uiux-master) | عندما تريد مراجعة شاشة أو رحلة كاملة تجمع النص واتجاه RTL وإتاحة الاستخدام |

لتثبيت المهارة المرافقة:

```bash
npx skills add theonlym7md/arabic-ai-skills --skill arabic-uiux-master
```

اسم المشروع **ArabicSkill** ومعرّف التثبيت **arabicskill**. إذا كنت تستخدم `arabic-intelligence` سابقًا، ابدأ من [دليل الانتقال](docs/MIGRATION.md).

## الفرق في النتيجة

| الحالة | قبل | بعد |
| --- | --- | --- |
| **دفع غير مؤكد** | فشل الدفع. حاول مجددًا. | **لم نتأكد من حالة الدفع بعد**<br>تحقّق من حالة العملية قبل الدفع مرة أخرى.<br>الزر: «تحقّق من الحالة» |
| **متجر يسمح بالتصفح دون حساب** | سجّل الدخول للمتابعة | **تصفّح المنتجات**<br>الإجراء الأساسي: «تصفّح المنتجات»<br>البديل: «سجّل الدخول» إذا أردت متابعة طلب قائم. |
| **بوابة تخدم أفرادًا ومنشآت** | اختر نوع الحساب | **كيف تستخدم البوابة؟**<br>«أتابع طلبًا شخصيًا» أو «أدير طلبات منشأتي»؛ يبدأ كل خيار المسار المناسب. |

أمثلة تحريرية توضيحية، وليست نتائج مقارنة بين نماذج. كل زر يفترض أن المنتج يدعم الإجراء المذكور.

## ما الجديد في 2.2

- **تصميم المسار، لا النص وحده:** ستة أنماط للمصادقة، وستة للدفع والسلة والتسعير، مع إرشادات للحجز وتوجيه الاستمارات حسب هدف المستخدم.
- **رسائل أكثر تحديدًا:** تدفقات للرموز المؤقتة والتحقق داخل النماذج، ورسائل تفرّق بين نتيجة مؤكدة ونتيجة غير مؤكدة في واجهات الذكاء الاصطناعي.
- **عربية أوضح داخل الواجهة:** لا نقطة ختامية في العناوين والأزرار والشارات. التوطين يحافظ على المتغيرات والمفاتيح وصيغ الجمع، وإرشادات RTL تفرّق بين الحقول الرقمية والحقول التي تقبل الحروف والأرقام.
- **تكامل برمجي ينتقي الإرشادات بحسب الطلب:** يدعم تحديد المنطقة واللهجة، ويستبعد الخيارات الطويلة أو التي تخالف قاعدة النقطة في العناوين والأزرار والشارات المعروفة.

## للمطوّرين

التكامل البرمجي اختياري. يتطلب Node.js 22 أو 24، ومفتاح OpenAI للطلبات الحية فقط.

```bash
npm ci
npm run check
npm run build
node examples/sdk.cjs
```

[مثال التكامل](examples/sdk.cjs) · [حدود التنفيذ](SPEC.md) · [دليل التوافق](docs/COMPATIBILITY.md)

يرسل التكامل سياق المنتج إلى OpenAI وقد تترتب تكلفة؛ لا ترسل بيانات حساسة. استخدام `store: false` افتراضيًا ليس ضمانًا شاملًا لعدم الاحتفاظ بالبيانات لدى المزود.
