# حالة تنبيه E005

في إصدار سابق، احتوى README داخل حزمة المهارة على أمر تثبيت ذاتي. أُزيل في [التغيير abc66ce](https://github.com/theonlym7md/arabic-ai-skills/commit/abc66ce)، وتوجد [مطالبة مفتوحة بإعادة الفحص](https://github.com/vercel-labs/skills/issues/2045) للمعرّف القديم `arabic-intelligence`. هذه المطالبة تختلف عن مسار المهارة الحالي `arabicskill`، لذلك لا ننسب نتيجة فحص القديم تلقائيًا إلى الجديد.

في مراجعة مصدر 2.0.1، لا تحتوي ملفات المهارتين على تعليمات تشغيل `npx` أو `curl` أو `wget`. أوامر التثبيت موجودة في README الجذري الموجّه للمستخدم الذي يختار التثبيت. يضم المستودع فحوص CI وCodeQL، ومرّ فحص `npm audit` المحلي لهذه النسخة دون ثغرات معلنة في تبعياته؛ لا تثبت هذه الفحوص خلو كل مخرجات الوكيل أو تكاملات الطرف الثالث من المخاطر.

إذا عرضت skills.sh تنبيهًا قديمًا، قارِن مسار المهارة وتاريخ الفحص والالتزام الذي فُحص مع [المصدر الحالي](https://github.com/theonlym7md/arabic-ai-skills/tree/main/skills/arabicskill). لا نصف التنبيه بأنه «مُحدّث» أو «منتهي» حتى يظهر فحص جديد بمرجع واضح. بلّغ عن أي سطر تنزيل أو تنفيذ مشبوه عبر [سياسة الأمان](../SECURITY.md)، واذكر مسار الملف والنسخة.
