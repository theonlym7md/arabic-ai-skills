# تجربة بناء صفحة دخول كاملة

استخدمنا [البرومبت نفسه](prompt.md) في جلستين مستقلتين من النموذج الموروث، دون مشاركة السياق أو المخرجات بينهما. الجلسة الأولى لم تقرأ أي مهارة، والثانية قرأت **ArabicSkill فقط**، بالإصدار [2.2.0](https://github.com/theonlym7md/arabic-ai-skills/tree/v2.2.0/skills/arabicskill)، الموافق للالتزام `819c010e08efe21c1170d32a66100fbab946434b`. لم نحدد لقطة ثابتة للنموذج أو بذرة التوليد.

الطلب يثبّت المنتج والوظائف، ويترك التصميم للمولّد: الألوان، والخطوط، والتخطيط، والنص، والرسوم والتفاعل. لا يوجد قالب مشترك، ونُسخت الصفحتان كما خرجتا. التقاط الصور بنفس المقاسات فقط يجعل العرض قابلًا للمقارنة. استُثنيت الصفحتان وحدهما من قاعدتي أسلوب في Biome حتى تبقى المخرجات الأصلية بلا تحرير.

افتح ملف HTML من نسختك المحلية لتجربة النموذج. الصفحتان تعملان محليًا، ولا ترسلان بريدًا أو بيانات. هذه عينة واحدة لكل شرط؛ اختلاف الألوان وحده لا يثبت تحسّن الجودة، وقد تخرج تصاميم أخرى عند إعادة التوليد.

لإعادة التقاط الصور، استخدم Node.js مع Playwright وChromium متاحين محليًا: `node docs/demos/login-build/capture.cjs`. يمكن ضبط `DEMO_BROWSER_PATH` لاستخدام Chrome مثبت. يمنع الفاحص الاتصالات الخارجية ويتحقق من اتجاه RTL ومن عدم وجود تمرير أفقي على العرضين.
