# ArabicSkill 2.2.0

من كتابة النص إلى اختيار مسار الواجهة. يضيف هذا الإصدار أنماطًا قابلة للتكييف للمصادقة والدفع والحجز والنماذج، مع أمثلة عربية واضحة في واجهة المشروع الجديدة.

- ستة أنماط للمصادقة وستة للدفع والسلة والتسعير، وإرشادات للعثور على المسار المناسب بحسب سياق المنتج.
- أمثلة ورسائل للتحقق داخل النموذج ورموز الدخول ونتائج الذكاء الاصطناعي غير المؤكدة.
- يدعم التكامل البرمجي اختيار المنطقة واللهجة، ويستبعد النقطة الختامية من أنواع العناوين والشارات والأزرار التي يتعرّف عليها.
- إرشادات أدق لحقول RTL: لوحة أرقام للرموز الرقمية، وحقل يقبل الحروف للآيبان.
- يشمل التقييم ٢١ حالة مرجعية، ويمكن تشغيل الفحوص المحلية دون استدعاء نموذج حي.

```sh
npx skills add theonlym7md/arabic-ai-skills --skill arabicskill
```
