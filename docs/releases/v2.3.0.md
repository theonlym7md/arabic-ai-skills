# ArabicSkill 2.3.0

ترقية معمارية وأمنية ولغوية شاملة للمهارتين، وحزمة Node.js SDK، وطبقة المعرفة والمدقّقات، والعرض المرئي.

- **توسيع المجالات وتصميم الصفحة:** إضافة دليل اختيار تصميم الصفحة المستقل في المهارتين، وتغطية كاملة لـ B2B SaaS والرعاية الصحية واسترداد الأخطاء والإشعارات وطيف النبرة، وقواعد الطباعة العربية (`letter-spacing: 0`) وهندسة RTL/WCAG 2.2 في `arabic-uiux-master`.
- **حزمة SDK معيارية وآمنة (CJS + ESM):** تأمين `baseURL` ضد SSRF، وإلغاء عبر `AbortSignal`، ومعالجة دقيقة لرفض النموذج والأخطاء المهيكلة (`ArabicSkillError`)، وتوحيد التوجيه من `routing.yaml`، وتقليص حجم البرومبت بالتحميل الانتقائي.
- **معمارية معرفة موحّدة:** 5 كيانات مجالية وإقليمية مع عزل `region_scope`، وملف أوزان وحيد (`weights.yaml`)، و3 مراحل متسلسلة (`stage_1`–`stage_3`)، و25 حالة قياس مرجعية مصنّفة بوضوح بين `sdk` و`agent`.
- **جودة لغوية ومرئية أدق:** تصحيح مصطلحات عربية وتقنية واللهجات داخل المراجع، وإصلاح حفظ الحركات والاتجاه RTL في مولّد الفيديو وتباين عروض المقارنة.

```sh
npx skills add theonlym7md/arabic-ai-skills --skill arabicskill
```
