# Security Policy

## Supported versions

Security fixes are applied to the latest release on `main`.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
**Report a vulnerability** option in the repository Security tab. Include the
affected file or workflow, reproduction steps, impact, and any suggested fix.

You can expect an initial acknowledgement within 7 days. Confirmed issues will
be fixed on a private branch and disclosed after a patched release is available.

Never include API keys, access tokens, private customer copy, or regulated data
in issues, benchmark fixtures, examples, or pull requests.
