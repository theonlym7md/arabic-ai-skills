# Code of Conduct

ArabicSkill is committed to providing a welcoming, inclusive, and professional open-source environment for all contributors.

## Standards
- Respect diverse viewpoints and cultural nuances.
- Maintain constructive, professional communication.
- Focus on technical excellence and objective evaluation.

## Scope and Reporting
These standards apply across all repository spaces: issues, pull requests, code reviews, discussions, and release channels. Report unacceptable behavior privately to the repository maintainers using the private reporting path noted in [SECURITY.md](SECURITY.md) (or by opening a private maintainer contact on GitHub). Maintainers review reports and may remove offending content or restrict participation when necessary.
