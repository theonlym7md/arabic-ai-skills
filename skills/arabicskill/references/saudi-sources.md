# سجل مراجعة المواقع

تاريخ المراجعة: **2026-10-04**. راجعنا الأسطح العامة أدناه عبر النص المستخرج أو المتصفح عند تعذر الاستخراج. لم نسجّل دخولًا، أو نُكمل حجزًا أو دفعًا أو استثمارًا، أو نختبر كل الشاشات. الملاحظات وصف لما شوهد، لا شهادة جودة أو امتثال أو اعتماد من أصحاب المواقع. الروابط مصادر أولية، وقد تتغير صفحاتها.

هذا سجل مصادر، لا ملف يحمّل تلقائيًا لكل مهمة. قواعد التكييف والأمثلة الأصلية في [أنماط المجال](sector-patterns.md). لا نحتفظ بنصوص الحملات أو الأصول البصرية أو أسعارها؛ لا توجد مجموعة بيانات تدريب أو عملية ضبط نموذج.

## كيف نستخدم الملاحظات؟

الملاحظة مرتبطة بصفحة محددة. القاعدة في مرجع المجال **استنتاج تحريري للمشروع**، لا اقتباس أو سياسة رسمية. عند طلب نص خاص بإحدى العلامات، استخدم حقائق ومصطلحات المنتج الحالي أو مصدره المعتمد، ولا تجعل هذه اللقطة التاريخية مصدرًا لشروط مالية أو قانونية.

لإضافة مصدر لاحقًا، سجّل الرابط والتاريخ والسطح الذي شاهدته، وما لم تختبره، ثم اكتب قاعدة قابلة للتكييف ومثالًا أصليًا. لا تنقل صفحات كاملة أو بيانات أشخاص، ولا تزعم تحسن أداء نموذج دون تجربة موثقة.
