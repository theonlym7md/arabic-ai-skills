# سلامة التوطين

## ملفات الترجمة

- احفظ مفاتيح JSON والمتغيرات مثل `{name}` و`{{amount}}` و`%1$s` حرفيًا، وبالعدد نفسه لكل رسالة.
- لا تترجم وسوم HTML أو عناوين URL أو أسماء المتغيرات؛ ترجم النص الظاهر فقط.
- حافظ على الترميز وبنية JSON/ICU، ولا تضع تعليقات أو أسوار Markdown إذا طُلب JSON فقط.
- في ICU يمكن إضافة فئات الجمع المطلوبة للعربية، مع حفظ اسم وسيطة الجمع والمتغيرات داخل الفروع ومعناها؛ لا تفرض تساوي عدد المتغيرات على الملف كاملًا بعد إضافة فروع جديدة.

- إذا كانت الصيغة غير معروفة اسأل عن المحرك قبل اختراع بناء خاص به.

## الجمع والحياد الجندري

العربية ليست صيغة مفرد وصيغة جمع فقط. استخدم فئات CLDR التي يدعمها المحرك:
`zero`, `one`, `two`, `few`, `many`, `other`.
اختبر 0 و1 و2 و3 و11 و100 وقيمة عشرية. لا تستخدم `count === 1`
قاعدةً مكتملة للعربية. القواعد النحوية للاسم والسياق تحتاج مراجعة أيضًا.
لا تستنتج جنس الشخص من اسمه؛ فضّل صياغة محايدة عند غياب معلومة موثوقة:

- تجنّب الصيغ المقطّعة مثل `أدخل/أدخلي` أو إلحاق تاء تأنيث مقيدة بالجنس عند مخاطبة جمهور عام. فضّل المصدر أو البناء الصالح للجميع أو صيغة المتكلم الجمعي (مثلًا: «حُفظت إعداداتك»، «أهلًا بك»، «تأكيد الحذف؟»، «متابعة حذف الحساب؟»، أو «هل نتابع الحذف؟» بدل «هل أنت متأكد؟» و«هل تريد متابعة الحذف؟»).
- في أزرار الإجراءات القصيرة، يُعد فعل الأمر غير المشكول («أضف»، «أرسل»، «احفظ») العرف العربي القياسي المقبول للجميع في واجهات المنتجات.

## الأرقام والتواريخ والعملات والمحتوى ثنائي الاتجاه

- احفظ قيمة المبلغ والعملة والمعرّف كما وردت، ونسّق حسب locale المطلوب دون تحويل عملة أو تقويم من تلقاء نفسك.
- **اتساق نظام الأرقام:** لا تخلط الأرقام الغربية (`0123`) والشرقية (`٠١٢٣`) في الشاشة نفسها؛ وحّد النظام وفق سوق المنتج وإعدادات اللغة المعتمدة.
- **التواريخ الهجرية والميلادية:** سمِّ التقويم صراحةً عند احتمال اللبس أو استخدام التقويمين معًا (مثلًا: `15 رمضان 1448 هـ` مقابل `23 نوفمبر 2026 م`).
- **موضع العملة في RTL:** حافظ على ترتيب المبلغ والعملة المتفق عليه في السوق (مثل `1,200 ر.س` أو `1,200 SAR` أو `450 ج.م`) واعزل الرمز اللاتيني مع الرقم لمنع التفافهما على سطرين.
- لا تعكس أرقام الهاتف أو رمز التحقق أو الآيبان.
<!-- agent-only:start -->
- في HTML اعزل القيمة الديناميكية بـ `<bdi>`، واضبط `dir="ltr"` للمعرّفات والأكواد المعروفة و`dir="auto"` لحقول الإدخال (`input`/`textarea`) التي يكتب فيها المستخدم لغات مختلطة.
<!-- agent-only:end -->
- فضّل بيانات الاتجاه في الواجهة على إدخال محارف خفية في النص القابل للنسخ.
- إذا تطلّب النص الصرف محارف عزل اتجاه، وضّحها مرمّزةً بصيغة هروب Unicode (مثل `\u2066` و`\u2069`) واختبر النسخ.
