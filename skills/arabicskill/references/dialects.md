# اللهجات عند الطلب الصريح

اكتب بالفصحى المبسطة الواضحة («الفصحى البيضاء» الخالية من التكلف) إذا لم يحدد المستخدم بلدًا أو لهجة. لا تستنتج بلد الشخص من اسمه أو كلمة واحدة أو عنوانه، ولا تحوّل نصًا حكوميًا أو ماليًا حساسًا إلى لهجة بلا طلب واضح ومراجعة ملائمة.

<!-- agent-only:start -->
1. اطلب البلد أو السوق المقصود إذا قال المستخدم «بالعامية» فقط وكان الاختلاف سيغيّر الناتج.
<!-- agent-only:end -->
2. استخرج مفردات العلامة التي قدمها المستخدم، وحدد مقدار العامية المطلوب: خفيف أو محادثة كاملة.
3. اكتب نسخة واحدة متسقة؛ لا تخلط مفردات بلدان مختلفة أو فصحى ثقيلة مع عامية داخل الجملة نفسها.
4. حتى مع النبرة العامية الودودة، أبقِ أزرار الإجراءات قصيرة ورسائل الدفع والأخطاء الحرجة واضحة بلا تهويل أو سخرية.
5. راجع النص مع متحدث من السوق المقصود قبل النشر، خصوصًا في الأذونات والدفع والصحة.

| السوق المحدد | إشارة لغوية توضيحية | مثال حالة فارغة (عنوان بلا نقطة + وصف بنقطة) | مثال زر / خطأ خفيف |
| --- | --- | --- | --- |
| فصحى مبسطة (الافتراضي) | الآن | العنوان: «لا توجد مهام بعد» · الوصف: «أضف مهمة لتبدأ تنظيم عملك.» | الزر: «أضف مهمة» · الخطأ: «تعذّر الحفظ، حاول مجددًا.» |
| مصر، محادثة غير رسمية | دلوقتي | العنوان: «لسه مفيش مهام» · الوصف: «ضيف مهمة عشان تبدأ.» | الزر: «ضيف مهمة» · الخطأ: «ما قدرناش نحفظ، جرّب تاني.» |
| السعودية، محادثة غير رسمية | الحين | العنوان: «ما عندك مهام للحين» · الوصف: «أضف مهمة وابدأ شغلك.» | الزر: «أضف مهمة» · الخطأ: «ما قدرنا نحفظ الحين، جرّب مرة ثانية.» |
| لبنان وسوريا، غير رسمية | هلّق | العنوان: «ما في مهام هلّق» · الوصف: «ضيف مهمة وبلّش.» | الزر: «ضيف مهمة» · الخطأ: «ما قدرنا نحفظ، جرّب كمان مرة.» |
| الأردن، غير رسمية | هسّا | العنوان: «ما في مهام هسّا» · الوصف: «ضيف مهمة وبلّش.» | الزر: «ضيف مهمة» · الخطأ: «ما قدرنا نحفظ، جرّب مرة ثانية.» |
| المغرب، دارجة غير رسمية | دابا | العنوان: «ما كاين حتى مهمة دابا» · الوصف: «زيد مهمة باش تبدا.» | الزر: «زيد مهمة» · الخطأ: «ما قدرناش نسجّلو التغييرات، عاود جرّب.» |

هذه أمثلة تحريرية تقريبية، وليست مصنفًا آليًا للهجات أو قاموسًا صالحًا لكل منطقة أو فئة عمرية. قد تختلف الصياغة داخل البلد الواحد؛ اعتمد لغة المستخدم ومصطلحات المنتج المعتمدة بعد مراجعة بشرية. لا تغيّر المتغيرات أو الأرقام أو المفاتيح عند تكييف اللهجة.
