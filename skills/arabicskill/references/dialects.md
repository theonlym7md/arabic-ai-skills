# اللهجات عند الطلب الصريح

اكتب بالفصحى الواضحة إذا لم يحدد المستخدم بلدًا أو لهجة. لا تستنتج بلد الشخص من اسمه أو كلمة واحدة أو عنوانه، ولا تحوّل نصًا حكوميًا أو ماليًا حساسًا إلى لهجة بلا طلب واضح ومراجعة ملائمة.

1. اطلب البلد أو السوق المقصود إذا قال المستخدم «بالعامية» فقط وكان الاختلاف سيغيّر الناتج.
2. استخرج مفردات العلامة التي قدمها المستخدم، وحدد مقدار العامية المطلوب: خفيف أو محادثة كاملة.
3. اكتب نسخة واحدة متسقة؛ لا تخلط مفردات بلدان مختلفة داخل الرحلة نفسها.
4. راجع النص مع متحدث من السوق المقصود قبل النشر، خصوصًا في الأذونات والدفع والصحة.

| السوق المحدد | إشارة لغوية توضيحية | مثال قصير لحالة مهام فارغة |
| --- | --- | --- |
| فصحى مشتركة | الآن | «لا توجد مهام بعد. أضف مهمة للبدء.» |
| مصر، محادثة غير رسمية | دلوقتي | «لسه مفيش مهام. ضيف مهمة عشان تبدأ.» |
| السعودية، محادثة غير رسمية | الحين | «ما عندك مهام للحين. أضف مهمة وابدأ.» |
| لبنان، محادثة غير رسمية | هلّق | «ما في مهام هلّق. ضيف مهمة وبلّش.» |
| المغرب، دارجة غير رسمية | دابا | «ما كايناش مهام دابا. زيد مهمة باش تبدا.» |

هذه أمثلة تحريرية تقريبية، وليست مصنفًا آليًا للهجات أو قاموسًا صالحًا لكل منطقة أو فئة عمرية. قد تختلف الصياغة داخل البلد الواحد؛ اعتمد لغة المستخدم ومصطلحات المنتج المعتمدة بعد مراجعة بشرية. لا تغيّر المتغيرات أو الأرقام أو المفاتيح عند تكييف اللهجة.
