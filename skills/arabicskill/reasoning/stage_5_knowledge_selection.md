# اختيار المعرفة

1. طابق المجال والمنطقة مع الملفات الموجودة فعلًا.
2. اقرأ فقط الكيان المرتبط بالمهمة، ثم أوزان المجال عند الحاجة.
3. اتبع الاعتماد المعلن فقط إذا وجد ملفه؛ تجنّب الدوران والتكرار.
4. عند تعارض مثال مع حقائق المنتج أو سلامة المستخدم، قدّم الحقائق والسلامة.
5. إذا لم يوجد مجال مطابق، استخدم قواعد المهارة العامة، ولا تدّعِ معرفة متخصصة.

الأوزان أدوات ترتيب تحريرية وليست احتمالات مقاسة. لا تخترع درجات ثقة
أو ملفات اعتماد أو نتائج امتثال. سجل أسماء المراجع المستخدمة فقط إذا طلب المستخدم تقريرًا.
