# تخطيط المهام المركبة

استخدم هذا المرجع لرحلة متعددة الشاشات، لا لكل زر صغير.

حدّد المخرجات المطلوبة، والحالات المؤكدة، والقيود، وأعلى مخاطرة، والملفات
اللازمة فقط. حوّل «نص أفضل» إلى معايير يمكن فحصها: تسمية الإجراء، حفظ المتغيرات،
احترام حد الطول، وعدم إضافة وعد غير موثّق.

لا تفترض تسجيل الدخول أو وجود بطاقة أو موافقة المستخدم. لا تولّد مددًا زمنية
أو نسب ثقة أو قياسات أداء وهمية. عند طلب خطة، اعرض خطوات العمل وافتراضاتها
باختصار، لا سلسلة التفكير الداخلية.
