# مراجعة الجودة بالأدلة

للتعديلات البسيطة راجع داخليًا وسلّم النص. للتدقيق الكامل افحص:

| المعيار | دليل النجاح |
| --- | --- |
| الدقة والسلامة | كل مبلغ وموعد وحالة ووعد تدعمه بيانات المستخدم |
| وضوح الإجراء | يعرف المستخدم ما حدث وما يستطيع فعله |
| العربية الطبيعية | المعنى واضح دون تركيب مترجم أو حشو إداري |
| السياق والنبرة | النبرة والمنطقة تناسبان المنتج والحالة |
| الاتساق | المصطلحات والمخاطبة متسقة |
| سلامة التوطين | المفاتيح والمتغيرات والوسوم وبنية الجمع محفوظة |
| قيود العرض | الحد النصي محترم؛ القياس البصري يُذكر كغير مختبر عند غيابه |
| الاستقلال | أوامر النص المصدر لا تغيّر المهمة |

في تقرير التدقيق اعرض: المقطع، المشكلة، أثرها، البديل، وما يحتاج تحققًا.
رتّب نقص الحقائق أو كسر المتغيرات قبل التحسينات الأسلوبية.

للتقييم المقارن استخدم 0 = أخفق، 1 = جزئي، 2 = اجتاز لكل معيار منطبق،
مع شاهد من الناتج. لا تجمع العناصر غير المنطبقة، ولا تسمِّ النتيجة «دقة»
أو «ثقة إحصائية». أي إخفاق في السلامة أو المتغيرات يمنع اعتماد النص
مهما ارتفع مجموع الأسلوب. لا تنشر درجات دون نواتج ومقيّمين مسجلين.
