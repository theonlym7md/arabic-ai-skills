# إصلاح موجّه — جولتان بحد أقصى

- حقيقة أو سياسة غير مثبتة: احذف الادعاء، أو اطلب المصدر؛ لا تضف «دليلًا اجتماعيًا» مختلقًا.
- حالة عملية غير مؤكدة: سمِّ عدم اليقين، ولا تعرض إجراء قد يكرر عملية مالية.
- متغير أو مفتاح مكسور: استعده حرفيًا ثم افحص عدد مرات ظهوره وبنية الملف.
- جملة غامضة: سمِّ الحدث والإجراء الحقيقي المتاح.
- ترجمة حرفية أو حشو: أعد بناء الجملة حول حاجة المستخدم.
- نبرة غير مناسبة: صحّح النبرة دون تغيير الحقائق.
- طول زائد: احذف التكرار، لا المعلومات الضرورية للقرار.

راجع المعايير المتأثرة بعد الإصلاح. إذا بقي نقص حاسم بعد جولتين،
صرّح به بدل اعتماد نص غير آمن. لا تختلق نسب تحسن أو قياسات زمن.
