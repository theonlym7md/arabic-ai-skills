# ArabicSkill

مهارة منظمة لكتابة النصوص العربية داخل المنتجات وتوطينها وتدقيقها. تجمع بين بوابة سياق، واختيار معرفة حسب المجال، وقواعد كتابة عربية، ومراجعة جودة قابلة للتكرار.

## متى تستخدمها؟

- الأزرار والحقول ورسائل الخطأ والحالات الفارغة
- الإشعارات وتهيئة المستخدم وصفحات الهبوط
- توطين تجربة منتج للعربية
- تدقيق نصوص عربية موجودة وتحسينها
- مواءمة النبرة مع المجال والمنطقة

## الاستخدام

بعد تثبيت المهارة من صفحة المشروع، ابدأ من [SKILL.md](SKILL.md). تُحمّل ملفات `reasoning/` و`knowledge/` و`plugins/` عند الحاجة فقط.

للمهام المتخصصة، اقرأ القسم المناسب من [أنماط المجال](references/sector-patterns.md). [سجل المواقع](references/saudi-sources.md) يوثّق المصادر وحدود مراجعتها؛ ليس دليلًا رسميًا للعلامات أو شروطًا مالية وقانونية دائمة.
