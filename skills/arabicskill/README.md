# ArabicSkill

مهارة منظمة لكتابة النصوص العربية داخل المنتجات وتوطينها وتدقيقها وتحديد مسار محتوى الشاشة. تجمع بين بوابة سياق، واختيار معرفة حسب المجال والمنطقة، وقواعد كتابة عربية، ومراجعة جودة قابلة للتكرار. لتفاصيل CSS المنطقية والطباعة العربية وتدقيق RTL الكامل للشاشات، استخدم المهارة المصاحبة `arabic-uiux-master`.

## متى تستخدمها؟

- الأزرار والحقول ورسائل الخطأ والحالات الفارغة
- الإشعارات وخصوصية شاشة القفل وتهيئة المستخدم وصفحات الهبوط
- تدفقات الذكاء الاصطناعي والمصادقة وOTP والدفع والتقسيط واسترداد الأخطاء
- توطين تجربة منتج للعربية (JSON/ICU والجمع والأرقام والتواريخ)
- تدقيق نصوص عربية موجودة وتحسينها ومواءمة النبرة مع المجال والمنطقة

## الاستخدام

بعد تثبيت المهارة من صفحة المشروع، ابدأ من [SKILL.md](SKILL.md). تُحمّل ملفات `reasoning/` و`knowledge/` و`plugins/` عند الحاجة فقط.

المراجع المتخصصة في `references/`:
- [أنماط المجال وطيف النبرة](references/sector-patterns.md) — صياغة حسب مجال المنتج (بما يشمل B2B SaaS والرعاية الصحية)
- [قرارات تصميم الصفحة](references/design-decisions.md) — مقارنة التكوينات بحسب هدف المستخدم والمحتوى والهوية والجهاز
- [أنماط التجربة القابلة للاختيار](references/experience-patterns.md) — بدائل الدخول، الدفع والسلة، الحجز والاستمارات، التنوع البصري، وضبط النقطة في العناوين
- [أنماط التدفقات الحديثة](references/ui-flows.md) — واجهات الذكاء الاصطناعي، المصادقة وOTP، التحقق المضمن، إتاحة الوصول، استرداد الأخطاء، والإشعارات والتهيئة
- [سلامة التوطين](references/localization.md) — JSON/ICU، الجمع، الحياد الجندري، الأرقام والتواريخ والعملات، وعزل الاتجاه
- [حالات تحتاج حقائق المنتج](references/sensitive-states.md) — الدفع غير المؤكد، الحذف، الأذونات، والصحة
- [دليل اللهجات](references/dialects.md) — التزام الفصحى افتراضيًا وضوابط اللهجات عند الطلب الصريح
- [سجل المصادر وحدود المراجعة](references/saudi-sources.md) — توثيق الـ 71 موقعًا المفحوصًا، والنطاقات المستبعدة، ومراجعة التأسيس الأولية وحدود الفحص

أمثلة تحريرية في `examples/`: [مقارنة الصياغة](examples/bad_vs_good_copy.md) و[حالة المخالفات الفارغة](examples/govtech_violation_empty_state.md) و[أمثلة برمجيات الأعمال والدفع وتنوّع النبرة](examples/saas_and_checkout_copy.md).
