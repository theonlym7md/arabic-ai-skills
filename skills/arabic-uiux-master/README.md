# ArabicSkill — UI/UX Master

مهارة عملية مستقلة تجمع تصميم ومراجعة الشاشات العربية مع هندسة اتجاه RTL والطباعة العربية والمحتوى ثنائي الاتجاه وإتاحة الوصول (WCAG 2.2) والميكروكوبي السياقي. لمهام كتابة النصوص الصرفة أو توطين ملفات JSON/ICU واللهجات دون تخطيط شاشة، استخدم `arabicskill`.

## متى تستخدمها؟

- تصميم أو مراجعة شاشة عربية كاملة من البداية
- بناء نظام نصوص وتدفقات لمسارات الدخول والدفع والنماذج والتصفية
- ضبط خصائص CSS المنطقية والطباعة العربية والمحتوى ثنائي الاتجاه (`<bdi>`)
- مراجعة الأزرار والنماذج والأخطاء والحالات الفارغة والوصولية وتباين الواجهة
- تقديم ملاحظات UX/RTL عربية قابلة للتنفيذ

## الاستخدام

بعد تثبيت المهارة من صفحة المشروع، راجع [SKILL.md](SKILL.md) لعقد التنفيذ وصيغة التسليم، واطّلع على [جدول مراجعة الشاشة ثلاثي الأعمدة](examples/screen_review_table.md) كنموذج تطبيقي جاهز.

المراجع المستقلة المضمّنة داخل هذه المهارة (لا تتطلب تثبيت المهارة الرئيسية):

- [أنماط التصميم وتدفقات الواجهة](references/flow-patterns.md) — الشخصيات البصرية الخمس، وبوابات المصادقة الست، ومسارات الدفع الستة، وقواعد النقطة الختامية والنماذج وRTL
