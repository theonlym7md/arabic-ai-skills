# Arabic UI/UX Master

مهارة عملية تجمع كتابة واجهات عربية واضحة مع إرشادات RTL والمحتوى ثنائي الاتجاه والطباعة وإتاحة الاستخدام.

## متى تستخدمها؟

- تصميم أو مراجعة شاشة عربية كاملة
- كتابة نظام نصوص لواجهة أو رحلة مستخدم
- مواءمة المحتوى مع RTL
- مراجعة الأزرار والنماذج والأخطاء والحالات الفارغة
- تقديم ملاحظات UX عربية قابلة للتطبيق

## الاستخدام

بعد تثبيت المهارة من صفحة المشروع، راجع [SKILL.md](SKILL.md) لعقد التنفيذ وصيغة التسليم، واطّلع على [جدول مراجعة الشاشة ثلاثي الأعمدة](examples/screen_review_table.md) كنموذج تطبيقي جاهز.

للشاشات المتخصصة والأنماط المعمارية وتدفقات المصادقة والدفع (تحديث `2.2.0`) استخدم [مرجع المجال](references/sector-screens.md) و[دليل أنماط التدفق والتكوين](references/flow-patterns.md)، وكلاهما مستقل داخل هذه المهارة ولا يتطلب تثبيت المهارة الرئيسية.

- التزام كامل بمنع النقطة الختامية في العناوين الرئيسية والبطاقات والأزرار والشارات
- خمسة أنماط معمارية وبصرية، وست بوابات مصادقة، وستة مسارات للدفع والتسعير، وحالات البث الذكي والتحقق السطري و`RTL/<bdi>`
