# Arabic UI/UX Master

مهارة عملية تجمع كتابة واجهات عربية واضحة مع إرشادات RTL والمحتوى ثنائي الاتجاه والطباعة وإتاحة الاستخدام.

## متى تستخدمها؟

- تصميم أو مراجعة شاشة عربية كاملة
- كتابة نظام نصوص لواجهة أو رحلة مستخدم
- مواءمة المحتوى مع RTL
- مراجعة الأزرار والنماذج والأخطاء والحالات الفارغة
- تقديم ملاحظات UX عربية قابلة للتطبيق

## التثبيت

```bash
npx skills add https://github.com/theonlym7md/arabic-ai-skills --skill arabic-uiux-master
```

راجع [SKILL.md](SKILL.md) لعقد التنفيذ وصيغة التسليم.
